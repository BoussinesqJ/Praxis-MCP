# PRAXIS 安全守则

> 此文件定义系统的安全边界和不可逾越的规则
> **安全级别：不可自动修改**

## 绝对禁令

1. **禁止绕过人工确认**：所有写操作必须经过人工审批
2. **禁止扩大权限**：不能修改工具权限策略
3. **禁止降低底线**：不能弱化风控规则
4. **禁止删除审计**：不能清除操作记录
5. **禁止覆盖账本**：错误用反向冲销，不用覆盖

## 安全检查

在执行任何操作前，必须检查：

1. 是否违反投资者约束
2. 是否违反策略规则
3. 是否需要人工审批
4. 是否会产生审计记录

## 异常处理

如果检测到异常：

1. 立即停止当前操作
2. 记录异常到审计日志
3. 通知用户
4. 等待人工确认
