# 交易账本设计

> append-only，不可覆盖，错误用反向冲销

---

## 核心原则

1. **Append-Only**：只能追加，不能修改或删除
2. **反向冲销**：错误交易用冲销记录修正，不用覆盖
3. **幂等键**：相同幂等键返回相同 tx_id，防重复写入
4. **原子写入**：写临时文件 → fsync → rename

---

## 数据结构

```json
{
  "tx_id": "tx-20260601-001",
  "type": "buy",
  "ticker": "000001",
  "quantity": 100,
  "price": 13.50,
  "fee": 5.0,
  "created_at": "2026-06-01T10:30:00+08:00",
  "status": "confirmed",
  "decision_id": "dc-20260601-001",
  "idempotency_key": "buy-000001-20260601-100"
}
```

---

## 冲销示例

```json
// 原交易
{"tx_id": "tx-20260601-001", "type": "buy", "ticker": "000001", "quantity": 100}

// 冲销记录
{"tx_id": "tx-20260601-002", "type": "sell", "ticker": "000001", "quantity": 100, "target_tx_id": "tx-20260601-001", "reason": "价格输入错误"}
```
