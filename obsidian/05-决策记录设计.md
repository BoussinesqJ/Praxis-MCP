# 决策记录设计

> 记录每次决策的上下文，回答"为什么这么做"

---

## 核心价值

**交易记录**回答：做了什么？
**决策记录**回答：为什么这么做？依据是什么？预期是什么？风险是什么？

---

```json
{
  "decision_id": "dc-20260601-001",
  "timestamp": "2026-06-01T10:25:00+08:00",
  "ticker": "000001",
  "action": "buy",
  "quantity": 100,
  "confidence": 0.75,
  "reasoning": "回踩MA20支撑，缩量企稳",
  "ai_team_signals": {
    "asrg": {"recommendation": "buy", "confidence": 0.68},
    "masters": {"recommendation": "hold", "confidence": 0.55},
    "trading": {"recommendation": "buy", "confidence": 0.75}
  },

  "review_20d": null,
  "review_60d": null
}
```

## 审批流程

```
AI 建议 → Decision Record (pending_approval)
    ↓
人工审批 → approved / rejected
    ↓
执行 → 生成 transaction → 写入 ledger
    ↓
复盘 → 5d/20d/60d 后自动回填
```

---

## 复盘机制

| 复盘类型 | 时间点 | 回填内容 |
|:--------:|:------:|---------|
| 5d | 5日后 | 实际价格、实际收益率 |
| 20d | 20日后 | 实际价格、实际收益率 |
| 60d | 60日后 | 实际价格、实际收益率 |

---

## AI 团队评价

每个团队的建议都会被追踪：

- 建议命中率
- 信心度校准误差
- 过度交易倾向
- 漏报风险次数

---

## Alpha 追踪 — Agent Tracking（v3.0 新增）

> 量化每个 AI Agent 的真实贡献，超越简单的"建议命中率"

### 三层追踪体系

| 层级 | 工具 | 能力 |
|:----:|------|------|
| **记录** | `agent_tracking(action="record")` | 记录每个Agent的决策（agent_id, ticker, action, confidence, reasoning） |
| **共识** | `agent_tracking(action="consensus")` | 检查多Agent对同一标的的一致性（min_agents=2） |
| **排名** | `agent_tracking(action="rank")` | 按决策数量和平均置信度排名所有Agent |

### Alpha 计算逻辑

```
Alpha = Σ(Agent_i 的决策命中收益) - 基准收益
```

- 每次决策关联 `agent_id`（如 reasonix / gemini / claude）
- 复盘时自动回填实际收益
- 按团队/Agent维度聚合，计算校准误差

### 数据流

```
决策创建 → agent_tracking.record(agent_id, ticker, decision_action, confidence)
    ↓
复盘回填 → review_tool(action="fill") — 自动匹配 5d/20d/60d 数据
    ↓
绩效聚合 → get_ai_tracking() → 按团队维度出报告
```

> MCP 工具：`agent_tracking`（action: record / consensus / rank）

## 延迟反思 — Review Tool（v3.0 新增）

> 自动回填到期复盘，让每次新决策都能参考历史反思

### 自动回填机制

```python
# 一键回填所有到期的 5d/20d/60d 复盘
review_tool(action="fill")

# 获取复盘汇总（待复盘/已复盘数量）
review_tool(action="summary")

# 获取指定团队的信心度校准误差
review_tool(action="calibration", team="asrg")
```

### 复盘数据用途

| 用途 | 说明 |
|------|------|
| **信心度校准** | 对比 Agent 预测置信度 vs 实际命中率，发现过度自信/过度保守 |
| **延迟反思注入** | `/quick-check` Step 0 注入最近复盘教训（避免重复犯错） |
| **进化引擎输入** | 为策略进化提供实证数据（非事后叙事） |

### 与进化引擎的联动

```
review_tool(fill) → 回填实际数据
    ↓
evaluate_evolution() → 基于复盘数据评估进化维度
    ↓
auto_evolve() → 生成策略调整建议
```
