# 决策记录设计

> 记录每次决策的上下文，回答"为什么这么做"

---

## 核心价值

**交易记录**回答：做了什么？
**决策记录**回答：为什么这么做？依据是什么？预期是什么？风险是什么？

---

## Decision Record Schema

```json
{
  "decision_id": "dc-20260601-001",
  "timestamp": "2026-06-01T10:25:00+08:00",
  "ticker": "STOCK_A",
  "action": "buy",
  "quantity": 100,
  "confidence": 0.75,
  "reasoning": "回踩MA20支撑，缩量企稳",
  "ai_team_signals": {
    "asrg": {"recommendation": "buy", "confidence": 0.68},
    "masters": {"recommendation": "hold", "confidence": 0.55},
    "trading": {"recommendation": "buy", "confidence": 0.75}
  },
  "status": "executed",
  "review_5d": null,
  "review_20d": null,
  "review_60d": null
}
```

---

## 审批流程

```
AI 建议 → Decision Record (pending_approval)
    ↓
人工审批 → approved / rejected
    ↓
执行 → 生成 transaction → 写入 ledger
    ↓
复盘 → 5d/20d/60d 后自动回填
```

---

## 复盘机制

| 复盘类型 | 时间点 | 回填内容 |
|:--------:|:------:|---------|
| 5d | 5日后 | 实际价格、实际收益率 |
| 20d | 20日后 | 实际价格、实际收益率 |
| 60d | 60日后 | 实际价格、实际收益率 |

---

## AI 团队评价

每个团队的建议都会被追踪：

- 建议命中率
- 信心度校准误差
- 过度交易倾向
- 漏报风险次数
