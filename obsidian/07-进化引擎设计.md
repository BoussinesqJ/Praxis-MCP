# 进化引擎设计

> 基于绩效数据，非事后叙事

---

## 核心原则

1. **数据驱动**：进化必须基于绩效数据，不能凭感觉
2. **安全约束**：修改前自动备份，修改后需人工审批
3. **可回滚**：所有修改都可回滚到旧版本
4. **可验证**：修改后需回测验证

---

## 进化维度

```yaml
evolution_dimensions:
  - name: "grid_spacing"
    desc: "网格间距是否过密或过疏"
    metric: "avg_days_between_triggers"
    healthy_range: [5, 30]

  - name: "stop_loss_tightness"
    desc: "止损线是否过紧"
    metric: "recovery_pct_within_5d"
    threshold: 50

  - name: "cost_anchor_effectiveness"
    desc: "成本锚定是否有效摊薄"
    metric: "avg_cost_reduction_pct"
    threshold: 3

  - name: "cash_floor_calibration"
    desc: "现金底线是否合理"
    metric: "unused_cash_ratio"
    healthy_range: [30, 60]
```

---

## 进化流程

```
评估进化维度
    ↓
生成进化建议（基于数据）
    ↓
备份策略文件
    ↓
人工 Diff 终审
    ↓
执行修改
    ↓
验证效果
```
