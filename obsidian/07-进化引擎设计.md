# 进化引擎设计

> 基于绩效数据，非事后叙事

---

## 核心原则

1. **数据驱动**：进化必须基于绩效数据，不能凭感觉
2. **安全约束**：修改前自动备份，修改后需人工审批
3. **可回滚**：所有修改都可回滚到旧版本
4. **可验证**：修改后需回测验证

---

## 进化维度

```yaml
evolution_dimensions:
  - name: "grid_spacing"

  - name: "stop_loss_tightness"

    metric: "unused_cash_ratio"

```

## 灰度验证 — Grayscale Validation（v3.0 新增）

> 策略变更先在沙箱中验证，通过后再正式应用

### 两阶段审批

```
策略变更建议
    ↓
prepare_grayscale(strategy_name, change_description, risk_level, validation_days)
    ↓ 创建灰度验证任务 → 备份当前策略
    ↓
验证期（默认30天）
    ↓ 回测验证 + 小仓位实盘验证
    ↓
approve_grayscale(strategy_name, backup_path, new_content)
    ↓ 审批通过 → 应用策略变更
    ↓ 自动记录进化记忆
```

### 风险等级

| 风险等级 | 验证要求 | 说明 |
|:--------:|---------|------|
| **low** | 回测通过 | 参数微调（如网格间距 ±5%） |
| **medium** | 回测 + 模拟盘 | 结构性变更（如止损逻辑调整） |
| **high** | 回测 + 模拟盘 + 人工逐笔审批 | 核心逻辑变更（如新增交易规则） |

### 一键自进化

```python
# 一键完成：评估 → 建议 → 备份 → 待审批
auto_evolve(investor="demo", portfolio="core", strategy_name="grid_value")
```

> MCP 工具：`prepare_grayscale`、`approve_grayscale`、`auto_evolve`

## 进化记忆 — Evolution Memory（v3.0 新增）

> 记录每次进化的上下文与效果，避免重复试错

### 三层记忆

| 操作 | 说明 |
|------|------|
| `record` | 记录一次进化记忆（trigger_event: transaction / nav_record / manual） |
| `timeline` | 获取策略进化时间线（按时间排列所有变更） |
| `query` | 查询类似情况的历史记录（关键词匹配） |

### 触发时机

```yaml
trigger_events:
  - transaction    # 每笔交易后自动评估是否需要进化
  - nav_record     # 每日净值记录后评估趋势
  - manual         # 人工触发
```

### 进化记忆查询示例

```python
# 当发现止损频繁触发时，查询历史类似情况
evolution_memory(action="query", situation="止损频繁触发网格间距过密")
# → 返回过去5条类似情况的处理方案和效果
```

> MCP 工具：`evolution_memory`（action: record / timeline / query）

## 自适应规则 — Adaptive Rules（v3.0 新增）

> 从历史数据中学习自适应规则，经安全扫描后应用

### 规则生命周期

```
learn → draft（草稿）
    ↓ 安全扫描（自动）
    ↓ 人工审批
approve → active（生效中）
    或
reject → rejected（拒绝）
```

### 操作

```python
# 从历史数据学习自适应规则
adaptive_rules(action="learn")

# 列出所有规则
adaptive_rules(action="list")

# 审批规则
adaptive_rules(action="approve", rule_id="ar-20260617-001")
adaptive_rules(action="reject", rule_id="ar-20260617-002")
```

### 安全扫描

学习到的规则在进入 `draft` 状态前，自动进行：
- **参数边界检查**：规则参数不能超出安全范围
- **冲突检测**：新规则不能与现有规则矛盾
- **回测验证**：在历史数据上验证规则有效性

### 与进化引擎的关系

```
进化记忆（历史数据） → adaptive_rules(learn) → 自适应规则（draft）
    ↓ 安全扫描 + 审批
自适应规则（active） → 影响交易决策参数
    ↓ 效果追踪
进化记忆（record） → 下一轮学习
```

> MCP 工具：`adaptive_rules`（action: learn / list / approve / reject）
