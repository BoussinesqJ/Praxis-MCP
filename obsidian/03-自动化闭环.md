# ⚙️ 自动化闭环

> 收盘后全自动执行：对账 → 校验 → 进化

---

## 每日闭环流程

```
15:00 收盘
  ↓
[[portfolio_manager.py]] — 拉取行情 → 更新 [[finance_status_card.md]] → 回写 [[project.md]]
  ↓
[[check_invariants.py]] — 4大断言校验
  ↓
如有异常（止损/踏空/滑点）
  ↓
[[evolve_system.py]] — 四维归因审计 + 知识星球脱敏版
  ↓
[[daily_review_template.md]] — 生成复盘报告
  ↓
[[daily_post_template.md]] — 脱敏为星球帖子
```

## 关键函数

### [[portfolio_manager.py]]
- `main()` — 主入口
- `fetch_realtime_data()` — 腾讯API实时行情
- `fetch_historical_metrics()` — MA20趋势 + 量比
- `update_status_card()` — 更新 [[finance_status_card.md]]
- `update_project_tables()` — 回写 [[project.md]]

### [[check_invariants.py]]
- `check_ticker_alignment()` — 标的一致性
- `check_mathematical_balance()` — 账目守恒
- `check_version_integrity()` — 版本闭环（校验 [[long-term.md]] 与 [[project.md]]）
- `check_risk_boundaries()` — 风险边界

### [[evolve_system.py]]
- `generate_internal_audit()` — 内部四维归因
- `generate_planet_audit()` — 脱敏版审计
