# 写操作安全

> 幂等/原子/审计，三重保护

---

## 三重保护

### 1. 幂等键
```python
idempotency_key = "buy-600995-20260601-100"
# 相同幂等键返回相同结果，防重复写入
```

### 2. 原子写入
```
写入临时文件
    ↓
fsync
    ↓
rename 原子替换
```

### 3. 审计日志
```json
{
  "event_id": "evt-20260601-001",
  "event_type": "tool_call",
  "tool_name": "add_transaction",
  "parameters": {...},
  "result_summary": "交易已确认",
  "success": true
}
```
