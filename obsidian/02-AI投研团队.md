## 编排器 — Orchestrator（v3.0 新增）

> 统一编排三大团队的分析流程，管理子Agent调度与输出汇编

### 核心能力

| 能力 | 说明 |
|------|------|
| `plan` | 为指定团队生成分析任务计划 |
| `member_prompt` | 为指定成员生成子Agent分析 Prompt |
| `compile_prompt` | 为主理人生成汇编 Prompt（汇总所有成员输出） |

### 调用流程

```
orchestrator(plan, team="asrg", ticker="000001")
    ↓ 获取任务计划
orchestrator(member_prompt, team="asrg", member_id="ethan", model_hint="quick")
    ↓ 逐个生成成员 Prompt
orchestrator(compile_prompt, team="asrg", all_outputs={...})
    ↓ 汇编最终报告
```

## 模型分级路由 — Model Router（v3.0 新增）

> 根据任务复杂度自动选择 `quick` 或 `deep` 模型，15个子Agent 映射到两级

### 分级策略

| 级别 | 模型类型 | 适用场景 | 子Agent数 |
|:----:|---------|---------|:---------:|
| **quick** | 轻量模型 | 数据查询、格式化输出、简单判断 | 7 |
| **deep** | 推理模型 | 深度分析、多维论证、风险评估 | 6 |

### model_hint 参数

通过 `orchestrator(member_prompt)` 的 `model_hint` 参数控制：

```python
model_hint = "quick"  # 轻量模式：快速响应，适合数据密集型任务
model_hint = "deep"   # 深度模式：深度推理，适合策略分析类任务
```

**映射规则**：
- **ASRG 团队**：数据采集层 → quick，分析研判层 → deep
- **Masters 团队**：定量分析 → quick，定性判断 → deep
- **Trading 团队**：风控检查 → quick，裁决论证 → deep

> 配置文件：`praxis_sdk/core/model_router.py`

## 结构化输出校验 — Validator（v3.0 新增）

> 所有子Agent输出通过 Pydantic schema 校验，失败时正则降级

### 校验层级

```
Pydantic Schema 校验（严格模式）
    ↓ 失败
正则表达式降级提取（宽松模式）
    ↓ 失败
返回原始文本 + 警告标记
```

> 配置文件：`praxis_sdk/core/validator.py`
