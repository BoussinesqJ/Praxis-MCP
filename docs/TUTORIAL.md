## 第 0 章：这玩意儿能帮你做什么

### 一句话说清楚

**PRAXIS 是一个帮你在投资时"管住手"的 AI 工具。** 它不帮你预测涨跌，但它帮你做三件事：

1. **在你冲动交易之前拦住你** — 比如你半夜想 All-in 一只股票，它会提醒你"仓位超限了""现金不够了"
2. **每天自动扫描市场情绪** — 8 只 ETF 像雷达一样告诉你今天是该进攻还是防守
3. **帮你算清楚每一分钱的来龙去脉** — 你赚了多少、亏了多少、最大回撤是多少，全都算得明明白白

### 它解决的核心痛点

| 痛点 | PRAXIS 的解法 |
|------|-------------|
| "看见涨就想追，看见跌就想割" | 交易前过 5 道纪律检查，不通过就拦下 |
| "不知道现在市场是热还是冷" | 哨兵雷达每天扫描 8 只 ETF，告诉你今天该几成仓 |
| "沪深300 现在贵不贵？" | PE-TTM 分位一看就知道，比历史上 70% 的时间都贵？那就小心点 |
| "账户赚了多少亏了多少，算不清楚" | 自动对账，FIFO（先进先出）算成本，实时行情算盈亏 |
| "复盘不知道看什么" | 12 项绩效指标 + 持仓周期分布 + 周报自动生成 |

### 完整工作流 — 一张图看懂

```
  每天早上开盘前                    盘中                        收盘后 / 周末
  ┌──────────────┐         ┌──────────────┐         ┌──────────────┐
  │ 1. 打开软件   │  ───→  │ 2. 哨兵扫描   │  ───→  │ 3. 更新净值   │
  │   连上 MCP    │        │   看市场情绪   │        │   记录当天数据 │
  └──────────────┘         └──────┬───────┘         └──────┬───────┘
                                  │                        │
                                  ▼                        ▼
                           ┌──────────────┐         ┌──────────────┐
                           │ Rule 23 触发? │         │ 4. 跑对账     │
                           │ 情绪起爆器    │         │   更新持仓盈亏 │
                           └──────┬───────┘         └──────┬───────┘
                                  │                        │
                                  ▼                        ▼
                           ┌──────────────┐         ┌──────────────┐
                           │ 交易前过约束   │         │ 5. 做复盘     │
                           │ 5 项硬检查    │         │   12 项指标   │
                           └──────┬───────┘         └──────┬───────┘
                                  │                        │
                                  ▼                        ▼
                           ┌──────────────┐         ┌──────────────┐
                           │ 执行交易      │         │ 得出明天思路  │
```

### TL;DR（太长不看版）

- 装好之后，每天花 **5 分钟**：扫一眼哨兵 → 查估值 → 做交易 → 记录净值
- 每周花 **15 分钟**：跑复盘 → 看周报 → 调整策略
- 每月花 **30 分钟**：看月度绩效 → 检视持仓结构 → 微调规则

**不需要编程，不需要 Python，所有操作都通过 WorkBuddy 对话完成。**

## 第 1 章：安装和配置

### 1.1 检查 Python

#### 你在做什么

确认你的电脑上装了 Python，而且版本不低于 3.11。

#### 你会看到什么

打开终端（Windows 按 `Win+R`，输入 `cmd` 回车；Mac 打开"终端"应用），输入：

```bash
python --version
```

如果输出类似这样，说明没问题：

```
Python 3.12.3
```

如果输出是 `Python 3.10.x` 或更早版本，需要升级 Python。

> **Windows 用户特别注意**：如果你装了 Python 但 `python` 命令不识别，试试 `python3`。如果还是没有，去 [python.org](https://python.org) 下载安装，**安装时务必勾选"Add Python to PATH"**。

#### 这意味着什么

PRAXIS 用了 Python 3.11 才有的新语法（比如 `type | None` 这种写法），所以版本不够就一定跑不起来。你不需要理解这些语法，只要确认版本号 ≥ 3.11 就行。

---

### 1.2 下载项目

#### 你在做什么

把 PRAXIS 的源代码下载到你的电脑上。

#### 方式一：用 git 克隆（推荐）

```bash
git clone https://github.com/BoussinesqJ/praxis-mcp.git
cd praxis-mcp
```

#### 方式二：下载 ZIP（不会用 git 的话）

1. 打开项目 GitHub 页面
2. 点击绿色的 `Code` 按钮 → `Download ZIP`
3. 解压到你喜欢的目录，比如 `C:\Users\<你的用户名>\Desktop\praxis-mcp`
4. 在终端里 `cd` 到解压后的目录

#### 这意味着什么

就是把代码搬到你的电脑上。后面所有命令都要在**项目根目录**（就是能看到 `pyproject.toml` 文件的那个目录）下执行。

---

### 1.3 创建虚拟环境 + 安装依赖

#### 你在做什么

Python 项目需要一个"隔离的小房间"（虚拟环境，也叫 venv），这样不会跟你电脑上其他 Python 项目打架。

#### 你会看到什么 — 三步走

**Step 1：创建虚拟环境**

```bash
# Windows（PowerShell 或 CMD）
python -m venv .venv

# Mac / Linux
python3 -m venv .venv
```

这一步不会有什么输出，但你会看到项目目录下多了一个 `.venv` 文件夹。

**Step 2：激活虚拟环境**

```bash
# Windows PowerShell
.venv\Scripts\Activate.ps1

# Windows CMD
.venv\Scripts\activate.bat

# Mac / Linux
source .venv/bin/activate
```

成功后，终端前面会出现 `(.venv)` 标记，像这样：

```
(.venv) C:\Users\你的用户名\Desktop\praxis-mcp>
```

**Step 3：安装项目**

```bash
# 基础安装（够用，不需要额外依赖）
pip install -e .

# 完整安装（含 AKShare 估值数据 + 测试工具，推荐）
pip install -e .[all]
```

安装过程中你会看到很多进度条和 `Successfully installed ...` 的字样，等它跑完就行。**整个过程大约 1-2 分钟**。

#### 这意味着什么

虚拟环境就是一个隔离的 Python 环境，PRAXIS 需要的库都装在这里面，不会影响你电脑上其他项目。以后每次使用 PRAXIS 之前，记得先激活虚拟环境（Step 2）。

---

### 1.4 配置 .env 文件

#### 你在做什么

PRAXIS 需要知道你的数据放哪里、日志级别是什么。这些配置都写在一个叫 `.env` 的文件里。

#### 你会看到什么

```bash
# 复制配置模板
cp .env.example .env
```

然后用你喜欢的文本编辑器（记事本、VS Code 都行）打开 `.env` 文件。**你只需要关心这几项：**

| 配置项 | 说明 | 怎么填 |
|--------|------|--------|
| `PRAXIS_WORKSPACE` | 数据存放目录 | 填一个绝对路径，比如 `C:\Users\<你>\praxis-data` |
| `PRAXIS_EMERGENCY_TOKEN` | 紧急解锁密码 | **必须填！** 用下一条命令生成 |
| `PRAXIS_LOG_LEVEL` | 日志详细程度 | 保持 `INFO` 就行 |

生成紧急解锁 Token：

```bash
# Mac / Linux
openssl rand -hex 32

# Windows PowerShell（没有 openssl 的话）
-join ((48..57)+(65..90)+(97..122) | Get-Random -Count 64 | ForEach-Object {[char]$_})
```

把生成的 64 位字符串填到 `.env` 里：

```
PRAXIS_EMERGENCY_TOKEN=刚才生成的那一串64位字符
```

**其他配置项不用管**，默认值已经是最佳实践。

#### 这意味着什么

`.env` 就是 PRAXIS 的"设置页面"。最重要的是 `EMERGENCY_TOKEN`，它是你的"总控钥匙"——当系统因为风控锁定不能交易时，用它来紧急解锁。**这串字符不要告诉任何人**。

### 1.6 接入 WorkBuddy

#### 你在做什么

让 PRAXIS 成为 WorkBuddy 的 MCP 工具，这样你就可以在对话里直接调用了。

#### 你会看到什么

打开 WorkBuddy 的 `mcp.json` 配置文件，找到 `mcpServers` 部分，添加以下内容：

```json
{
  "mcpServers": {
    "praxis-agent": {
      "command": "python",
      "args": ["-m", "praxis.cli"],
      "cwd": "<你的路径>/praxis-mcp",
      "env": {
        "PRAXIS_WORKSPACE": "<你的路径>/praxis-data",
        "PRAXIS_EMERGENCY_TOKEN": "你在1.4步生成的64位token",
        "PRAXIS_STORAGE_BACKEND": "sqlite",
        "PRAXIS_LOG_LEVEL": "INFO",
        "PRAXIS_LOG_JSON": "true",
        "NO_PROXY": "*"
      }
    }
  }
}
```

> **记得替换 `<你的路径>`**！比如 `cwd` 填 `C:/Users/张三/Desktop/praxis-mcp`。

保存后重启 WorkBuddy，在对话里输入"帮我扫描一下哨兵"，如果 PRAXIS 开始回应了，说明配置成功。

#### 这意味着什么

MCP（Model Context Protocol，模型上下文协议）就像给 AI 装了一个"工具箱"。配置好之后，WorkBuddy 就能调用 PRAXIS 里的 29 个工具来帮你做投资分析。

### 常见踩坑

| 问题 | 现象 | 解决方法 |
|------|------|---------|
| **Python 版本不对** | `SyntaxError` 或 `type | None` 报错 | `python --version` 确认是 3.11+，如果不是就升级 |
| **pip 装不上** | `pip: command not found` | 确认激活了虚拟环境（前面有 `(.venv)`），或者用 `python -m pip` |
| **路径有空格** | `No such file or directory` | 路径中如果有空格（比如 `praxis MCP`），用引号包起来，或在 mcp.json 里用正斜杠 `/` |
| **PowerShell 不让执行脚本** | `cannot be loaded because running scripts is disabled` | 以管理员身份运行 PowerShell，执行 `Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser` |
| **mcp.json 找不着** | WorkBuddy 里没有 PRAXIS 工具 | 确认 `cwd` 是绝对路径、`command` 是 `python`（不是 `python3`，除非你在 Mac 上） |
| **AKShare 装不上** | `pip install akshare` 报错 | 这是可选依赖，不影响核心功能。先跳过，估值功能需要时再单独装 |

### 2.2 运行哨兵扫描：看市场情绪

#### 你在做什么

这是 PRAXIS 最有特色的功能 —— 哨兵雷达。它会同时扫描 8 只 ETF，判断每只是看多、看空还是中性，然后告诉你今天应该用几成仓位。

#### 你会看到什么

在 WorkBuddy 里输入：

> "运行哨兵扫描"

PRAXIS 会输出类似这样的结果：

```
📡 哨兵雷达扫描结果 — 2026-01-15

【大局风格层】
  510300 沪深300ETF      ¥3.98  bullish   量平 (1.05)
  159915 创业板ETF       ¥2.38  bullish   异常放量 (1.72)
  512000 券商ETF         ¥0.92  neutral   量平 (0.95)
  159601 恒生科技ETF     ¥0.68  bullish   量平 (1.10)

【执行持仓层】
  512480 半导体ETF       ¥1.15  bullish   静默缩量 (0.55)
  515050 通信ETF         ¥1.32  neutral   量平 (0.88)
  515220 煤炭ETF         ¥1.56  bearish   异常放量 (1.63)
  511220 国债ETF         ¥102.3 bearish   量平 (1.02)

──────────────────────────────────
📊 看多: 4/8  |  市场状态: 适度试探期
💰 建议仓位上限: 20%
🔥 Rule 23 情绪起爆器: 未触发
```

#### 这意味着什么

你会看到每个 ETF 后面有三个关键信息：

- **bullish / bearish / neutral（趋势方向）**：价格在 20 日均线（MA20）上方 1% 以上叫"看多（bullish）"，在 MA20 下方 1% 以下叫"看空（bearish）"，中间叫"中性（neutral）"
- **量能描述**：`异常放量` 意味着今天成交量是近 5 天平均的 1.5 倍以上，可能有大事发生；`静默缩量` 意味着不到 0.6 倍，市场很冷清；`量平` 就是正常
- **Rule 26 仓位阶梯**：这个是自动根据"多少只 ETF 在看多"来算的

**Rule 26 仓位阶梯表：**

| 看多数量 | 市场状态 | 建议最大仓位 | 你该怎么做 |
|---------|---------|------------|----------|
| 0–2 只 | 绝对防守期 | **10%** | 减仓或观望，只拿防御性资产 |
| 3–4 只 | 适度试探期 | **20%** | 小仓位试试，严格止损 |
| 5–6 只 | 积极配置期 | **30%** | 逐步加仓，放宽止损 |
| 7–8 只 | 全面进攻期 | **50%** | 市场全面回暖，可积极配置 |

### 2.3 理解哨兵输出：Rule 23 情绪起爆器

#### 你在做什么

了解 Rule 23 —— 它帮你捕捉"市场情绪从冷转暖"的那个关键转折点。

#### Rule 23 是什么

**连续 2 个交易日，看多 ETF 数量都 ≥ 4 只**，就会触发"情绪起爆器"信号。

#### 你会看到什么

如果触发了，哨兵输出会多一行：

```
🔥 Rule 23 情绪起爆器: 已触发 (连续第 3 天)
⚠️  操作提示: 市场情绪确认回暖，可考虑加仓至仓位阶梯上限
```

#### 这意味着什么

Rule 23 就像"温度计突破 20 度，春天来了"。单日回暖可能是假信号，但**连续两天都暖**，说明趋势比较稳。这时候你可以考虑按 Rule 26 给的仓位上限来加仓。

**重要**：Rule 23 是信号不是命令。它告诉你可以加仓，但加不加、加多少，还是你自己决定。

---

### 2.4 查估值分位：沪深 300 现在贵不贵

#### 你在做什么

用 PRAXIS 的估值引擎，看沪深 300（或者其他指数）当前的 PE（市盈率）在历史上处于什么位置。

#### 你会看到什么

在 WorkBuddy 里输入：

> "查一下沪深300的估值分位"

PRAXIS 会返回：

```
📈 估值分位 — 沪深300 (000300)

  当前 PE-TTM: 12.45
  全历史分位: 28.5%  ← 低于历史上 71.5% 的时间
  近 10 年分位: 35.2%

  30% 分位值 (低估线): 12.82
  80% 分位值 (高估线): 18.34

  判定: 🟢 undervalued（低估）
  数据量: 4560 个交易日
```

#### 这意味着什么

- **PE-TTM**（滚动市盈率）：比普通 PE 更准，因为它用最近 4 个季度的真实盈利来算，不是去年的老数据
- **全历史分位 28.5%**：把历史上每天的 PE 从小到大排，当前 PE 处于第 28.5% 的位置。也就是说，历史上 71.5% 的时间都比现在贵
- **判定规则**：
  - 分位 < 30% → 🟢 **低估**（便宜，适合定投/建仓）
  - 分位 30%–80% → 🟡 **合理**（正常持有）
  - 分位 > 80% → 🔴 **高估**（贵了，考虑减仓）

> **注意**：估值分位需要 `akshare` 库。如果没装，运行 `pip install akshare` 就行。

PRAXIS 覆盖 4 个指数：

| 代码 | 名称 | 一句话 |
|------|------|--------|
| 000300 | 沪深300 | 大盘蓝筹代表 |
| 000016 | 上证50 | 超大市值代表 |
| 000905 | 中证500 | 中盘成长代表 |
| 000852 | 中证1000 | 小盘代表 |

## 第 3 章：管理你的持仓

### 3.1 录入交易记录

#### 你在做什么

每次买入或卖出之后，把交易记录到 PRAXIS 里。系统用这些记录来自动算持仓、成本和盈亏。

#### 你会看到什么

在 WorkBuddy 里输入：

> "记录一笔买入：600519 贵州茅台，买了 100 股，成交价 1680 元，手续费 5 元"

或者：

> "记录卖出：000001 平安银行，卖了 500 股，成交价 12.50 元，手续费 2.5 元"

PRAXIS 会返回确认信息：

```
✅ 交易已记录

  类型: 买入
  标的: 600519 贵州茅台
  数量: 100 股
  价格: ¥1,680.00
  金额: ¥168,000.00
  手续费: ¥5.00
  时间: 2026-01-15 14:35:00
  交易ID: tx-abc123
```

#### 这意味着什么

每笔交易都会写入 **Ledger（交易账本）**。这是一个 append-only（只追加不修改）的记录，就像银行流水一样，每条记录都有时间戳、不可篡改。系统会基于这个账本自动算出你的持仓。

**买入：** 持仓份额增加，成本按移动加权平均法更新
**卖出：** 持仓份额减少，先买的那部分先卖出（FIFO，先进先出）

---

### 3.2 跑一次对账：系统自动算持仓和盈亏

#### 你在做什么

让 PRAXIS 把交易账本"翻译"成持仓状态 —— 你现在持有什么、成本多少、赚了亏了多少。

#### 你会看到什么

在 WorkBuddy 里输入：

> "帮我对账"

PRAXIS 会返回：

```
=== 组合状态快照 ===
投资者: default
组合: main
快照时间: 2026-01-15T16:00:00

--- 资产总览 ---
总资产: ¥200,450.00
持仓市值: ¥172,300.00
可用现金: ¥28,150.00
现金比例: 14.0%

--- 持仓明细 ---
  600519 贵州茅台: 100股 × ¥1,689.00 = ¥168,900.00 (+0.5%)
  000001 平安银行: 500股 × ¥12.45 = ¥6,225.00 (-1.3%)
  510300 沪深300ETF: 无持仓 (当前价: ¥3.98)
```

#### 这意味着什么

对账引擎做了三件事：

1. **从账本重建持仓**：把你所有的买入卖出记录累加起来，用 FIFO 移动加权平均法算出每只股票的持仓成本和持仓量
2. **注入实时行情**：从数据源获取当前价格，算出市值和浮盈
3. **计算组合全景**：总资产 = 持仓市值 + 现金余额

`现金比例 14.0%` 这个数字很重要 —— 如果太低，说明你的"弹药"不够了，遇到好机会没钱加仓。

---

### 3.3 看组合全景

#### 你在做什么

在对账基础上，看更详细的组合结构 —— 各标的权重是否合理。

#### 你会看到什么

> "看我的组合全景"

PRAXIS 会返回每个持仓的权重和盈亏明细，帮你判断组合结构是否健康。

#### 这意味着什么

关注两点：
- **单标的权重**：如果茅台占了 84%，说明你的风险高度集中在一只股票上
- **现金比例**：低于 5% 时，系统在后续交易中会触发"现金底线"约束，拦下买入操作

### 3.4 更新净值：每天收盘后跑一次

#### 你在做什么

收盘后，把当天的账户净值记录到系统里。净值序列是做绩效分析的"原材料"。

#### 你会看到什么

在 WorkBuddy 里输入：

> "更新今天净值，总资产 200450，持仓市值 172300，现金 28150"

或者让系统自动算：

> "自动记录今天净值"

PRAXIS 会返回：

```
✅ 净值已记录

  日期: 2026-01-15
  净值: 1.0245
  总资产: ¥200,450.00
  持仓市值: ¥172,300.00
  现金: ¥28,150.00
```

#### 这意味着什么

净值（NAV）是一个相对值：净值 = 总资产 ÷ 初始本金。如果初始本金是 14 万，现在总资产是 20 万，那净值就是 1.4286。

**每天收盘后坚持记录净值**，积累 20 个交易日以上的数据后，绩效分析就会非常准确。

> ⚠️ 每天只能记录一次净值，重复记录会被拒绝。

### 4.2 理解每个指标（大白话版）

#### 收益指标

| 指标 | 大白话 | 怎么看 |
|------|--------|--------|
| **累计收益** | 从开始到现在总共赚了多少 | > 0 就是赚钱了 |
| **年化收益** | 折算成一年的收益率 | > 10% 算不错 |
| **超额收益** | 跑赢大盘多少 | > 0 说明比直接买沪深300强 |
| **基准收益** | 同期大盘涨了多少 | 对比用的，判断你有没有白忙 |

#### 风险指标

| 指标 | 大白话 | 怎么看 |
|------|--------|--------|
| **最大回撤** | 你最惨的时候，从最高点跌了多少 | < 20% 算稳健，> 30% 要注意 |
| **年化波动率** | 你的账户每天上蹿下跳的程度 | 越低越稳，太高说明持仓太刺激 |
| **夏普比率** | 每冒一分风险，赚了几分钱 | > 1 算合格，> 2 算优秀 |
| **Calmar比率** | 年化收益 ÷ 最大回撤 | > 1 说明赚的比亏的多 |

#### 交易指标

| 指标 | 大白话 | 怎么看 |
|------|--------|--------|
| **胜率** | 你买卖 10 次，有几次是赚钱的 | > 50% 就行，不需要 100% |
| **盈亏比** | 你赚的时候平均赚多少 vs 亏的时候平均亏多少 | > 1.5 说明赚大亏小 |
| **换手率** | 你买卖有多频繁 | 太高说明你在"炒"，太低可能太保守 |
| **总手续费** | 给券商交了多少钱 | 关心一下就行 |

> **特别说明**：PRAXIS 的绩效计算基于 NAV（净值）序列，不是简单的 (卖出-买入)/本金。这意味着它考虑了时间、波动、回撤等所有因素，算出来的数据更真实。

---

### 4.3 看持仓周期分布：你是短线选手还是长线选手

#### 你在做什么

PRAXIS 自动分析你的买卖记录，看你的持仓周期集中在哪个区间。

#### 你会看到什么

```
📅 持仓周期分布

  < 3 天（短线）:    ████████ 8 笔  (40%)
  3–7 天（短中期）:  ██████ 6 笔    (30%)
  7–20 天（中期）:   ████ 4 笔      (20%)
  > 20 天（长线）:   ██ 2 笔        (10%)

  已配对: 20 笔
  未配对: 3 笔（仍持有中）
```

#### 这意味着什么

- **短线占比高（>50%）**：你可能在频繁交易，手续费和情绪损耗会很大。考虑放慢节奏
- **长线占比高（>50%）**：你是价值投资者，但也检查一下持仓中是否有"被迫长线"（套牢了不想卖）
- **各档均衡**：说明你的策略比较灵活

系统用的是 **FIFO 配对法**：每笔卖出按"先买先卖"的原则找到对应的买入记录，然后算持有的天数。

## 附录 D：自定义数据源（进阶）

PRAXIS 的数据源是插件式的。如果你有自己的行情服务（比如企业内部的 Wind 终端、自建的行情数据库），可以写一个自定义提供器接进来。

### 快速开始

在项目的 `providers/` 目录下新建一个 `.py` 文件，比如 `my_provider.py`：

```python
"""我的自定义行情源"""
from praxis.core.interfaces import DataProvider

# 优先级：数字越小越优先（3 比所有内置源都高）
PRIORITY = 3

class MyProvider(DataProvider):
    """对接我的自建行情服务"""

    async def get_realtime_quote(self, tickers: list[str]) -> dict[str, dict]:
        # 返回格式: {ticker: {name, price, prev_close, open, ...}}
        ...

    async def get_history_kline(self, ticker: str, period: str = "day",
                                 count: int = 60) -> list[dict]:
        ...

    async def close(self) -> None:
        ...
```

系统启动时会**自动发现**这个文件并注册为数据源。你可以在 `config/data_sources.yaml` 里显式启用或禁用。

> 这是一个进阶功能，大多数用户不需要。如果你感兴趣，可以看 [README 中的"自定义信源"章节](../README.md#14-自定义信源) 了解完整说明。
